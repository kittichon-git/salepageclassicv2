## Color Contrast (WCAG AA — minimum 4.5:1 normal text, 3:1 large text)

| Foreground      | Background       | Ratio  | Normal text | Large/Bold | Notes                          |
|-----------------|------------------|--------|-------------|------------|--------------------------------|
| charcoal-900 #3a3530 | cream-100 #f2ecdd | ~9.1:1 | ✓ Pass | ✓ Pass | Body text, headings           |
| charcoal-700 #5a5048 | cream-100 #f2ecdd | ~6.1:1 | ✓ Pass | ✓ Pass | Secondary body text           |
| cream-50 #f8f3e6 | coral-500 #d27355 | ~3.0:1 | ✗ Fail | ✓ Pass (≥18px bold) | Primary CTA (not used in practice — all CTAs use LINE green or ghost) |
| white #ffffff    | LINE green #00b900 | ~2.6:1 | ✗ Fail | ✗ Fail  | **Brand constraint** — LINE OA color cannot be changed; accepted risk |

**Action items:**
- `primary` CTAButton variant: if used with small text, switch background to `coral-700 (#9a4d36)` which achieves ~5.4:1. Currently no section uses `variant="primary"` — risk is low.
- LINE green button: accepted brand constraint. Add `title` attr or supplementary text for assistive tech if needed.
