## Interactive Elements

- All `<Link>` and `<button>` have accessible labels
- CTA icon: `aria-hidden="true"` on MessageCircle ✓
- All decorative Lucide icons: `aria-hidden="true"` ✓
- Portrait placeholder: `aria-label={instructor.name}` ✓
- Curriculum carousel: `role="region" aria-label="หลักสูตร 7 ภาค" tabIndex={0}` ✓
- FAQ: native `<details>/<summary>` — keyboard accessible ✓

## Focus Ring

```css
:focus-visible {
  outline: 2px solid var(--color-amber-500); /* #ddb049 */
  outline-offset: 2px;
}
```

Amber focus ring on navy/cream backgrounds — high visibility.

## Contrast Table

| Element | Foreground | Background | Ratio | Pass |
|---------|-----------|-----------|-------|------|
| Body text | navy #233149 | paper #fffdf7 | ~12:1 | ✓ AAA |
| Body text | navy #233149 | cream #fbf5e8 | ~11:1 | ✓ AAA |
| Eyebrow/badge | cream #fbf5e8 | teal #2f8588 | ~4.6:1 | ✓ AA |
| Testimonial | cream #fbf5e8 | dark-navy #253751 | ~10:1 | ✓ AAA |
| CTA text | white #ffffff | LINE green #00b900 | ~3.1:1 | ⚠ AA large only (accepted brand color) |
| Muted text | #5a6478 | paper #fffdf7 | ~6.5:1 | ✓ AA |

**Note:** LINE green (#00b900) at small text sizes fails AA by ~0.4 contrast ratio. Accepted as brand color constraint (same as S1 original).
